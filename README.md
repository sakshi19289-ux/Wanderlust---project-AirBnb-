# Wanderlust – Airbnb-Style Full-Stack Web Application

Wanderlust is a full-stack accommodation listing web application inspired by platforms like Airbnb. It allows users to create, view, edit, and delete property listings and add reviews.

## 🚀 Tech Stack

* **Frontend:** HTML, CSS, Bootstrap, EJS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Other:** Express Router, Server-side & Client-side Validation

## ✨ Features

* Create, view, edit, and delete accommodation listings
* User-friendly listing forms with validation
* Add and manage reviews for listings
* Review validation
* Organized routes using Express Router
* MongoDB database integration using Mongoose
* Responsive UI using Bootstrap
* Dynamic page rendering using EJS

## ⚙️ How to Run Locally

1. Clone the repository
2. Install dependencies:

   ```bash
   npm install
   ```
3. Start the application:

   ```bash
   node app.js
   ```
4. Open `http://localhost:8080` in your browser.
